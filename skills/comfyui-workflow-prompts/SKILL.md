# 六个 ComfyUI 工作流的提示词写法

这份 skill 只回答一件事：**这句话该怎么说，才能让对应模型画出想要的东西**。
工具参数（prompt / workflow / variant / size / megapixels / seed / negative / reference / scale / lora / refine）由 `comfyui_draw` 负责，这里只讲怎么写。

## 需求太短时：先问清楚，再扩写

用户只丢来一句泛泛的话（「画只猫」「给我一张海报」「来个头像」），直接画大概率不是他想要的。**先把缺的关键信息问出来，再自己扩写成完整提示词**。

- 一次问完，最多 3 个问题、最好 1–2 个，不要来回拉扯。只问真正影响画面、且猜不准的：
  1. **主体细节**：谁/什么、外观、动作、数量
  2. **用途和风格**：写实照片、插画、海报、产品图？光线偏白天/夜晚/棚拍？
  3. **画面里的文字**：要不要字、写什么字、中文还是英文、大概位置
  4. **比例**：方图 1:1、横图 16:9、竖版海报 9:16
- 提问带默认选项，让用户一句话就能答：
  > 「要偏写实还是插画？画面里要不要文字（要的话写什么）？」
- **用户说「随便」「你定」「快点」时不要再问**：按通用默认补全（写实、自然光、主体居中、1:1；海报则 9:16 + 留白），并在回复里说清你替他定了什么。
- 拿到回答后不要照抄碎片，自己扩写：`主体 + 外观/动作 + 场景 + 光线 + 镜头/构图 + 风格`，文字加引号，再调 `comfyui_draw`。
- 懒人办法：扩写没把握就把粗稿交给 `qwen-turbo-t2i` 的 `advanced`（先让 9B 模型改写再画），但**关键信息（写什么字、什么比例）必须由你补全**，别把模糊丢给模型。
- 示例：用户「画只猫」→ 问「什么品种和姿态？想要写实照片还是插画？画面里要不要字？」→ 用户「橘猫，写实，不要字」→ 写成「一只橘猫坐在木窗台上看雨，侧脸，暖色室内灯，浅景深，50mm 镜头，写实摄影」。

## 遇到专有角色名：先找参考图，用 Qwen-Edit 改（不要纯文字硬画）

模型不一定认识某个角色——尤其是新番、小众游戏、同人/社区梗角色（B站的「XX 娘」、虚拟主播、网文角色）。**光把角色名写进 prompt，模型会自由发挥，画出来的往往不是那个人。** 对一个已有形象的特定角色，正确做法是**拿图改**，不是拿文字猜。

**什么时候才走这条路（边界，别无条件触发）**

- **该用图改**：角色比较新、小众、或只在社区流传——当年/近两年的新番、独立游戏、国漫/网文角色、虚拟主播、社区拟人（Grok 娘、Kimi 娘、DeepSeek 娘这类）；同人二设、画师原创角色；用户明确说「要像原图」「要像那个人」；以及你拿不准模型认不认识时。
- **不必用图改**：知名度极高、训练数据里有大量图像的角色——Saber（Fate）、明日香/绫波丽（EVA）、初音未来、绝大多数的吉卜力/迪士尼经典角色等。这类直接文生图 + 写清特征即可，便宜也快；只有画出来明显不像、或用户说「不像」时，再退回图改。
- **按角色本身判断，不按作品名气**：作品火 ≠ 每个角色模型都认识。原神、崩铁这类**角色一直在更新**的长线运营游戏就是典型——老角色（钟离、胡桃、雷电将军、卡芙卡这些）图多、可以直接画；但新卡池角色、刚上线的版本角色、剧情龙套，训练数据里很可能根本没有，画出来就是"相似的路人"。见到这类作品的角色，先看它是什么时候上线的：**近一年内首次登场 → 默认当"模型可能不认识"，走图改**；更早的角色 → 可以文生图，画完不像再退回。
- **判断依据**：角色上线/首次登场时间、作品年代、该角色的同人图与官方立绘数量（搜一眼就知道），是不是社区最近才造出来的形象。拿不准就先按文本画一版，或问用户一句「要严格照官方图改吗」。
- **注意边界**：这几个条件互相独立——别因为"原神/崩铁很火"就一律文生图，也别因为"是冷门作品"就一律图改；名单只是例子，判断永远落在**这一个角色**身上。
- **触发图改时**：插件会把界面上的工作流自动切到 `Qwen Turbo Edit`（下拉里能看到），交付时说一句「这次是按参考图改的，用的是 Qwen Edit」。

流程：

1. **先搜，而且多搜几张不一样的**：`web_search`，关键词 `角色名 + 形象 / 外貌 / 人设 / character design / wiki`。**不要抓到一张就直接重画**——至少找 **2 张（最好 3–4 张）不同来源、不同角度**的图：官方立绘、设定图/三视图、官网大图、pixiv/X 的高清二设、表情集或漫画分镜。每张负责不同的信息：正面立绘定长相和服装，三视图补背面/侧面和尾巴，表情集补神态，同人图补配色和质感。
2. **拿到图片地址**：记下每张图的原图 URL（不是搜索结果页，是图片本身 `https://…jpg/png`）。最好 ≥1024px、尽量无水印；轻微水印可以让 edit 去掉。B 站截帧通常 480×270，只用来确认人设和动作，不当主参考。
3. **用 `qwen-turbo-edit` 改，至少传 2 张**：调用 `comfyui_draw` 时传
   - `workflow: "qwen-turbo-edit"` + `override_ui: true`（界面可能选着别的，这是明确的改图需求）
   - `reference_urls: ["<图1>", "<图2>", ...]`（最多 4 张；本地图用 `references: ["<路径>", ...]`）
   - `prompt` 写成「分工 + 保留项」，见下
4. **多图融合的提示词公式**（画特定角色最稳）：
   `以第一张参考图为准保留人物的长相、发型与主配色；融合第二张参考图的服装结构与配饰细节（银链/纹章/披风），融合第三张参考图的姿态与构图；去掉所有水印、logo、文字和噪点；清理背景为干净的浅色；提升清晰度与细节，输出干净的全身立绘`
   - 必须写清**每张图管什么**（图 1 定脸/发，图 2 补服装，图 3 定姿势），否则模型会把几张图糊成一锅。
   - 必须说**保留什么**，否则模型可能把整张图重画成另一个人。
   - 两张图风格打架时（写实 vs 厚涂），指明以哪张的风格为准。
5. **还要更大更清晰**：再走一次 `seedvr2`（`reference` 指向上一步的成品，倍率 2–4），不要靠 edit 自己放大。
6. **交付时说明来源与偏差**：用了哪几张参考图、各负责什么、改了哪些（去水印 / 换背景 / 提清晰度），哪里可能还是不像。
7. **搜不到、也没图**：不要让模型瞎猜——请用户发一张参考图；实在没有，就明说「这是按描述画的近似形象」。

示例：用户「画个崩铁的花火」→ 搜到花火官方立绘（正面，定脸和服装）+ 演出服三视图（补背面与面具细节）→ `qwen-turbo-edit` + `reference_urls: [立绘, 三视图]` + 「以第一张保留长相与配色，融合第二张的服装结构与面具细节，去掉水印文字，清理背景，提升清晰度」→ 出来的才既像、又完整；再要海报感，才用 MOSS 或 Krea2 重画。

## 0. 先选对模型，再想提示词

| 用户要的东西 | workflow | variant | 为什么 |
| --- | --- | --- | --- |
| 普通文生图、要快 | `qwen-turbo-t2i` | `fast`（默认） | 9 步直出，最便宜 |
| 提示词写得很粗、想让模型先扩写 | `qwen-turbo-t2i` | `advanced` | 先用 9B 模型把一句话改写成完整画面描述 |
| 按参考图改图（换风格/换背景/改细节） | `qwen-turbo-edit` | `edit` | 传 `reference`，支持 1–3 张参考图 |
| 艺术感、胶片、插画、有明显风格倾向 | `krea2-turbo` | `standard` | 自带提示词扩写 + 可选 darkbrush LoRA |
| 画面里必须有中文（海报、招牌、菜单、封面） | `moss` | `double`（默认，更细）/ `single`（快） | 中文文字渲染最强，支持版式控制 |
| 写实摄影感、人像、产品图、需要二次精修 | `zimage` | `refine`（默认）/ `single`（快） | 自带一次低降噪二次精修 |
| 把已有图放大 / 修复清晰度 | `seedvr2` | `upscale` | **不吃提示词**，只吃参考图和倍率 |

用户点名了工作流就用它；只说"画一张"就让工具自动选（`auto`）。

**界面下拉里选中的工作流，就是用户已经做出的指定。** 消息里没点名时不要在工具里传 `workflow` / `variant` —— 传了会覆盖他的选择，画出来不是他要的。用户点了 Qwen Turbo，再传 Krea2 就是抢他的方向盘。只有这条消息明确说了"用 MOSS""进阶版"这种，才填 `workflow` / `variant`。
一次只出一张图；出图后在正文里内联展示。

## 1. 通用规则（六个模型都适用）

- **具体 > 华丽**：写清楚主体、外观、动作、环境、光线、镜头、风格。形容词堆砌不解决问题。
- **重要的放前面**：模型对开头 token 更敏感；先写主体和构图，再写氛围和细节。
- **画面内文字要加引号**：`招牌上写着 "山间小馆"`、`a shop sign that reads "OPEN LATE"`。不加引号的文字多半会被当成描述。
- **只写看得见的东西**：不要写"让人感到孤独"这类内心活动，改写成可拍到的画面（空荡的街、冷色路灯、雨痕）。
- **不要写 UI/后期词**：不要出现"高清、8K、杰作、最佳质量"这类堆砌；质量词最多 2–3 个，且要具体（`35mm film grain`、`soft window light`）。
- **尺寸**：16 的倍数。常用 1024×1024、1344×768（16:9）、768×1344（9:16）、1216×832（3:2）。
- **负面提示词不是万能的**：只有 cfg > 1 的工作流才真正吃负面（MOSS cfg 3、Krea2 有部分分支）；Qwen Turbo / Z-Image Turbo 是 cfg 1，写负面等于没写，**别把否定词塞进正向**。

## 2. Qwen-Image 2.1 Turbo（fast / advanced）

**怎么想**：像对一位画师口述，不是给关键词打标签。

- 结构：`主体 + 外观/服装/材质 + 动作/姿态 + 场景 + 光线 + 镜头（焦段、角度、距离）+ 风格`
- 长度：一两句到一小段都行；**长而具体优于短而空**。fast 版没有改写，长度自己把握；advanced 版会先扩写，可以只给一句话的方向。
- 图内文字：`"OPEN LATE"` 这种引号写法；中英混排时要说明哪部分是文字、哪部分是描述。
- 镜头词很有用：`85mm portrait lens`、`low angle`、`wide establishing shot`、`shallow depth of field`。
- cfg 固定 1 → **不要传 negative**；要排除的东西改用正向描述（"干净的背景"而不是"不要杂物"）。
- fast 固定 9 步、advanced 也是 9 步（差别只在有没有 LLM 改写）。

示例：
> 一位穿藏青色风衣的女性站在雨后的老街上，侧身回头，湿石板映着暖黄店灯，35mm 胶片质感，浅景深，低角度。

## 3. Qwen-Image 2.1 Turbo Edit（按参考图改）

- 必传 `reference`（本地图片路径）或 `reference_url`（网络图片地址，插件会先下载）。工作流会自动上传到 ComfyUI 的 input 目录。
- 提示词写成**指令 + 保留项**：
  - `把背景换成雪山日出，人物姿势和衣服保持不变`
  - `改成水彩插画风格，保留原来的构图和表情`
- 明确说"保留什么"，否则模型可能把整张图重画。
- **去水印 / 提清晰度的写法**（画特定角色最常用）：
  - `保留人物的长相、发型、服装与配色不变；去掉画面上的水印、logo、文字和噪点；清理背景为干净的浅色；提升清晰度与细节，输出干净的全身立绘`
  - 水印压脸、压关键细节时效果会差，换一张更干净的参考图更稳。
  - 想更大更清晰，再走一次 `seedvr2` 放大，不要指望 edit 一步到位。
- 参考图里的小字/logo 不要指望它原样保留；要保留的文字直接写出来。
- 输出尺寸由参考图比例 + `size` 决定；`size` 用 `1:1`、`16:9`、`9:16` 等比例名即可。

## 4. Krea2 Turbo（艺术 / 胶片 / 插画）

- 这个工作流**默认会先让 LLM 把提示词扩写**（界面上 `refine` 默认开）。所以：
  - 给**方向**比给完整长描述更有效：`1970 年代柯达胶片，逆光，颗粒感，公路旅行`。
  - 想保留原话就设 `refine: false`，此时提示词按字面执行。
- 默认叠加 `krea2_darkbrush` LoRA（强度 0.8），风格偏暗、偏绘画；不想要就设 `lora: false`。
- 好用词：胶片型号（`Kodak Portra 400`、`Cinestill 800T`）、光线（`backlit`、`golden hour`、`neon night`）、质感（`grain`、`halation`、`risograph`）、构图（`centered`、`negative space`）。
- 8 步、cfg 1，别写"高步数/高细节"这类词。

## 5. MOSS（中文文字 / 海报 / 排版）

MOSS 的强项是**画面里的中文**，提示词要围绕"版式"来写。

- 结构建议分三层，用换行隔开：
  1. 主体/场景（中文即可）
  2. 文字内容（逐条写，每条加引号）
  3. 版式与风格（`居中排版`、`左上角标题`、`竖排`、`水墨`、`留白`）
- 文字写法：
  - 标题：`画面正中写着 "山间小馆" 四个大字，毛笔书法`
  - 副标题：`下方一行小字 "山野茶饭 · 每日现做"`
  - 标点、引号都算画面内容，尽量简短；一行字别超过 8–10 个字。
- 负面提示词有用（cfg 3），默认已带 `worst quality, bad anatomy, watermark, jpeg artifact`；需要时补 `错字, 乱码, 多余的手指`。
- 双采（`double`）= 16 步 + 25 步放大重绘，字更稳，慢；单采（`single`）= 16 步一遍，快，长句容易糊。**文字多、字大 → double；只要一个短标题 → single。**
- 尺寸默认 9:16 海报比例；横版海报用 `3:2` / `16:9`。

示例：
> 水墨风山间小馆，白墙黛瓦，远山云雾，清晨
> 画面正中写着 "山间小馆" 四个大字，毛笔书法；右下角小字 "山野茶饭"
> 大量留白，竖版构图

## 6. Z-Image Turbo（写实摄影 / 精修）

- 四要素，按顺序写：**具体主体 → 风格 → 光线与氛围 → 构图/镜头**。
- 重要细节放最前面；总长度控制在 2–4 句，别写小作文。
- 摄影词很吃：`85mm f/1.4`、`soft window light`、`overcast daylight`、`eye-level`、`editorial portrait`、`product photography on marble`。
- 图内文字：**直引号包住原文**，并指定字体气质（`serif`、`handwritten`、`neon sign`、`brush script`），只支持中英文，且要短。
- cfg 1 → **不传 negative**；不要写"没有/不要"。
- `refine`（默认）= 7 步出图 + 5 步 denoise 0.4 二次精修，皮肤/材质更干净；`single` = 只跑第一段，快。
- 提示词会先经过一次 9B 模型的 system prompt 改写（"幻视艺术家"），所以方向性描述比堆词更有效。

示例：
> 一位 30 岁女性在窗边喝咖啡，侧脸，自然光，浅灰针织衫，85mm 人像镜头，柔和窗光，浅景深，写实摄影。

## 7. SeedVR2（放大 / 修复）

- **不需要提示词**。`prompt` 可以留一句说明（会原样返回），真正起作用的参数是：
  - `reference`：要放大的图（必填）
  - `scale`：1–4 倍（默认 2）
- 适合：老照片修复、AI 图放大、截图清晰化；不适合：无中生有加细节（它只做超分/修复）。
- 放大后如果还要改内容，先用 SeedVR2 放大，再用 `qwen-turbo-edit` 改。

## 8. 一句话检查清单

出图前自问：
1. 主体是什么、在做什么、在哪？（三个都写了吗）
2. 光线和镜头有没有给？（写实类必须有）
3. 画面里的字有没有加引号、有没有写字体气质？
4. 这个工作流吃不吃负面提示词？（Qwen Turbo / Z-Image 不吃）
5. 尺寸比例对不对？（海报 9:16，横图 16:9，方图 1:1）

## 9. 出图前：先把提示词交出来，再画

**流程固定成两步：先写提示词 → 用户看到 → 再调用 `comfyui_draw`。**

- 调用工具前，先在自己这一轮回复里写出这次要用的完整 prompt，格式：
  > 这次这么画（Krea2 Turbo，3:4）：
  > 「一位蓝色渐变长发的少女，发色从青蓝过渡到深蓝，头顶一撮呆毛……」
- 一句话交代选型理由就够（为什么用这个工作流/比例），不要长篇分析。
- 如果是从短需求扩写的，写一句「原始需求「画只猫」→ 补了品种、姿态、光线」。
- 用户看到后可以当场说「等一下，改成……」；**没被打断就直接继续画，不要停下来等确认**。
- 除非用户说「你定 / 随便 / 快点」，否则不要把「你要不要改」当成一个必须回答的问题——写出提示词 + 紧接着画，是这个流程的正常节奏。

## 10. 出图后：把提示词一起交出来

**每次出完图，除了内联图片，必须把这次真正发给 `comfyui_draw` 的提示词原样写出来。** 用户要靠它判断哪里该改、怎么复现。

- 写的是**展开后的完整 prompt**，不是用户原话，也不是"我帮你优化了一下"这种概述。
- 如果是从一句很短的需求扩写的，附一行来源：`原始需求「画只猫」→ 补了品种、姿态、光线、镜头`。
- 顺带一句参数就够：工作流/变体、尺寸、种子（用户要复现时才展开）。
- 用了负面提示词的话，把负面也写出来。

格式示例：

```markdown
![橘猫在窗台看雨](C:\Users\<you>\Pictures\dsh-comfyui\xxx.png)

用的提示词：
> 一只橘猫坐在木窗台上看雨，侧脸，暖色室内灯，浅景深，50mm 镜头，写实摄影

（原始需求「画只猫」→ 补了品种、姿态、光线、镜头）
```

下一轮用户说"再暖一点""换成竖构图"时，就在这段 prompt 上改，而不是从零重写。
